# 宵崎奏桌宠

一个以宵崎奏为形象的桌面宠物主体原型。当前版本包含透明置顶窗口、呼吸与随机眨眼动画、拖拽移动、点击互动、休息状态和可展开的功能面板。

角色动画使用两张 1024 × 1024 高清透明 PNG 帧，并统一了角色比例、中心位置和脚底基线，因此眨眼切换时不会发生缩放或位移跳动。原始素材保存在 `assets/original/`。

## 运行

```bash
pnpm install
pnpm start
```

生成 macOS 应用与安装镜像：

```bash
pnpm package:mac
```

## 操作

- 拖动角色：进入后颈提起动作并移动桌宠，松开时回弹落下
- 单击角色：随机互动
- 双击角色或点击名字：打开主面板
- 主面板“睡觉/吃饭”：进入锁定状态，再次点击对应的停止按钮退出

连续 5 秒没有操作后，奏会以相同概率随机进入两种待机事件。睡觉使用“打哈欠抱被子 → 拉起被子 → 熟睡”三帧序列，随后循环呼吸并显示上浮的 `ZZZ`；吃面使用“拿出杯面 → 夹起面条 → 吸面”三帧序列，并循环播放后两帧。点击、移动或拖动会立即结束事件并重新计时。

主面板提供“睡觉”和“吃饭”手动状态。手动进入后不会被点击、移动或拖拽打断，只能再次点击对应的“停止睡觉/停止吃饭”按钮结束。面板还提供小、标准、大三档角色尺寸，并会记住上一次选择。

吃面三帧使用同一坐姿母版，锁定头部、头发、躯干、腿和鞋的比例与基线，仅改变手、杯面、筷子和面条，避免逐帧播放时身体发生位移跳动。

项目结构已将 Electron 主进程、页面和素材分开，后续可以继续加入对话、日程提醒、音乐播放、AI 聊天和系统托盘等模块。

## 本地更新

在主面板点击“安装本地更新”，选择文件名中带有更高语义版本号的 `.dmg`（例如 `宵崎奏桌宠-0.3.0-arm64.dmg`）。应用会比较当前版本，确认后打开镜像，引导用户将新版拖入“应用程序”并替换旧版。此模式适用于尚未配置开发者签名和在线更新服务器的本地分发阶段。
